# 行测指南 · 方法为先

面向零基础考生的公务员考试《行政职业能力测验》教学网站。覆盖**言语理解与表达、政治理论、判断推理、常识判断、数量关系、资料分析**六大模块的考点体系、解题方法与精讲例题——不堆知识点，只讲方法。

Live site: <https://nichuan.github.io/xingce-guide/>

## 站点特性

- **九章完整讲义**：从试卷全景认知，到六大模块精讲，再到备考路线图与速查工具箱；33 道精讲例题演示完整思考路径。
- **KaTeX 专业公式排版**：数量关系与资料分析的全部核心公式（基期量、间隔增长率、十字交叉、容斥原理、几何公式等）以 LaTeX 渲染，公式卡片高亮展示，移动端可横向滚动。
- **结构化教学容器**：提示 / 注意 / 说明 / 公式卡 / 记忆卡 / 例题六类视觉区块，答案自动渲染为徽章。
- **全站搜索**：`Ctrl + K` 唤起，按小节索引考点、公式与技巧，支持键盘导航。
- **阅读体验**：桌面端三栏布局（导航 / 正文 / 滚动高亮目录），移动端抽屉导航 + 底部目录面板；阅读进度条、回顶部按钮、明暗双主题（跟随系统，可手动切换）。
- **响应式适配**：375px～4K 全尺寸友好，表格横向滚动，安全区适配。

## 技术栈

Vite 7 · Vue 3 · TypeScript · vue-router · markdown-it + KaTeX。

内容与界面分离：所有章节内容位于 `src/content/*.md`（markdown + LaTeX + 自定义容器语法），站点结构由 `src/content/chapters.ts` 描述，新增或修改章节无需触碰组件代码。

### 自定义容器语法

```md
::: tip 提示标题
提示内容（`warn` 注意、`note` 说明同理）
:::

::: formula 核心公式
$$\text{基期量} = \frac{\text{现期量}}{1 + r}$$
:::

::: memo 记忆卡标题
口诀、必背清单等
:::

::: example 例 14 · 代入排除
> 题干……
>
> **解析**：……**答案 A**。
:::
```

## 开发

```bash
npm install
npm run dev       # 本地开发
npm run build     # 构建到 dist/
npm run preview   # 本地预览构建产物
```

推送至 `main` 分支后，GitHub Actions 自动构建并发布到 GitHub Pages（见 `.github/workflows/pages.yml`）。
