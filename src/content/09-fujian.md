## 附录 C 数量关系与资料分析核心公式速查

### 数量关系

| 主题 | 公式 |
|---|---|
| 工程 | $W = p \times t$；设总量为时间的最小公倍数 |
| 行程 | $S = v \times t$ |
| 相遇 | $S_{\text{总}} = (v_1 + v_2) \times t$ |
| 追及 | $S_{\text{差}} = (v_1 - v_2) \times t$ |
| 流水行船 | $v_{\text{顺}} = v_{\text{船}} + v_{\text{水}}$；$v_{\text{逆}} = v_{\text{船}} - v_{\text{水}}$；$v_{\text{水}} = \dfrac{v_{\text{顺}} - v_{\text{逆}}}{2}$ |
| 利润 | 利润 = 售价 − 成本；利润率 = 利润 ÷ 成本 |
| 浓度 | 溶质 = 溶液 × 浓度 |
| 排列 | $A_n^m = \dfrac{n!}{(n-m)!}$ |
| 组合 | $C_n^m = \dfrac{n!}{m!\,(n-m)!}$ |
| 概率（对立） | $P(\text{至少一个}) = 1 - P(\text{一个都没有})$ |
| 两集合容斥 | $\lvert A \cup B \rvert = \lvert A \rvert + \lvert B \rvert - \lvert A \cap B \rvert$ |
| 三集合容斥 | $\lvert A \cup B \cup C \rvert = \Sigma - \Sigma_{\text{两两交集}} + \lvert A \cap B \cap C \rvert$ |
| 圆 | 面积 $\pi r^2$，周长 $2\pi r$ |
| 球 | 表面积 $4\pi r^2$，体积 $\dfrac{4}{3}\pi r^3$ |
| 平均数混合 | 十字交叉：$A : B = \lvert r - b \rvert : \lvert a - r \rvert$ |

### 资料分析

| 主题 | 公式 |
|---|---|
| 基期量 | $\dfrac{\text{现期量}}{1 + r}$ |
| 增长量 | $\dfrac{\text{现期量} \times r}{1 + r}$ |
| 增长率 | $\dfrac{\text{增长量}}{\text{基期量}}$ |
| 间隔增长率 | $R = r_1 + r_2 + r_1 r_2$ |
| 年均增长率 | $r = \left(\dfrac{\text{末期}}{\text{初期}}\right)^{1/n} - 1$ |
| 比重 | $\dfrac{\text{部分}}{\text{整体}}$ |
| 基期比重 | $\dfrac{A}{B} \times \dfrac{1 + b}{1 + a}$ |
| 比重变化（百分点） | $\dfrac{A}{B} \times \dfrac{a - b}{1 + a}$ |
| 平均数增长率 | $\dfrac{a - b}{1 + b}$ |
| 倍数 | $A \div B$ |
| 是几倍 / 多几倍 | $A \div B$ ／ $A \div B - 1$ |
| 增长量比较 | 大多用"大大则大"：现期大且增速高者增长量必大 |
| 混合增长率 | 介于两部分之间，偏向基期量大的一方 |

::: note 符号约定
$a$ 为部分的增长率，$b$ 为整体的增长率；$A$ 为部分的现期量，$B$ 为整体的现期量。
:::

## 结语

行测是一门"方法重于天赋"的考试。它的题量决定了你不可能靠蛮力取胜，但它的规律性也决定了你一定可以靠方法取胜。

新手最容易犯的错误是"看到哪复习哪"，而正确做法是：**先建框架，再练方法，最后练节奏。**

祝备考顺利。
