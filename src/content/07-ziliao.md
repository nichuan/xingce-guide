资料分析是全站最应该反复研读的一章——它**单题分值最高（1.0 分），且方法完全可以通过训练掌握**。请务必把 7.2 的公式体系和 7.3 的速算技巧练到"条件反射"的程度。

## 7.1 模块概述与心法

资料分析考查对统计材料的阅读与运算能力。材料形式有文字型、表格型、图形型、综合型四种。题量 20 题，单题分值最高，**是全卷性价比最高的模块**。

::: memo 三条心法
1. **资料分析考的不是计算能力，而是"估算能力 + 公式熟练度"**。所有正确选项的差距都在合理范围内，用估算即可区分。
2. **先看问题，再回材料找数据**。不要通读材料，材料是"数据仓库"，不是"文章"。
3. **列式时间应占 70%，计算时间占 30%**。公式熟，式子列对了，答案基本就出来了。
:::

::: memo 标准做题流程
**读题干 → 判断考点（增长率？比重？平均数？）→ 回忆公式 → 回材料定位数据 → 列式 → 估算（截位直除等）→ 选答案**
:::

## 7.2 基础概念与公式体系

这是资料分析的"地基"，必须背熟到不假思索。

### 7.2.1 核心量之间的关系

设：现期量（本期值）$= A$，基期量（上期值）$= B$，增长率（增速）$= r$，增长量 $= \Delta$。

| 关系 | 公式 |
|---|---|
| 现期量 | $A = B \times (1 + r)$ |
| 基期量 | $B = \dfrac{A}{1 + r}$ |
| 增长量 | $\Delta = A - B = B \times r = \dfrac{A \times r}{1 + r}$ |
| 增长率 | $r = \dfrac{\Delta}{B} = \dfrac{A - B}{B}$ |

::: memo 最重要的记忆点
$$\text{基期量} = \frac{\text{现期量}}{1 + \text{增长率}}$$

这是资料分析出现频率最高的一个式子。
:::

### 7.2.2 同比与环比

- **同比**：与**去年同一时期**相比（如 2025 年 6 月与 2024 年 6 月）。
- **环比**：与**上一个相邻时期**相比（如 2025 年 6 月与 2025 年 5 月）。

::: note 默认口径
材料中不特别说明"同比增长率"时，通常指的是**同比**。
:::

### 7.2.3 间隔增长率

已知相邻两期的增长率分别为 $r_1$、$r_2$，求隔一期的增长率 $R$：

::: formula 间隔增长率
$$R = r_1 + r_2 + r_1 \times r_2$$

当 $r_1$、$r_2$ 都较小时（如 5% 以下），$r_1 \times r_2$ 可近似忽略：$R \approx r_1 + r_2$。
:::

### 7.2.4 年均增长率

设初期值为 $B$，末期值为 $A$，间隔 $n$ 年，年均增长率为 $r$：

::: formula 年均增长率
$$(1 + r)^n = \frac{A}{B}$$
:::

**估算技巧**（考试中极少要求精确解）：

- 当 $r$ 较小时，$(1+r)^n \approx 1 + n \cdot r$，故 $r \approx \dfrac{A \div B - 1}{n}$。这个估算值**偏小**，实际 $r$ 会比它略大。
- 比较两个年均增长率大小时，**只需比较 $A \div B$ 与 $n$ 的大小关系**，无需真正开方。

::: tip 秒杀技巧
若两个方案的"末期值 ÷ 初期值"比值为 $m$，年份数为 $n$，则年均增长率的大小由 $\dfrac{m}{n}$ 决定——比值大者年均增长率大。
:::

### 7.2.5 比重

::: formula 比重体系
其中 $A$ = 部分的现期量，$a$ = 部分的增长率；$B$ = 整体的现期量，$b$ = 整体的增长率。

| 考点 | 公式 |
|---|---|
| 现期比重 | $\dfrac{A}{B}$ |
| 基期比重 | $\dfrac{A}{B} \times \dfrac{1 + b}{1 + a}$ |
| 比重变化（百分点） | $\dfrac{A}{B} \times \dfrac{a - b}{1 + a}$ |
:::

::: tip 比重升降的秒杀判断
- 若 $a > b$（部分增速快于整体增速）→ 比重**上升**。
- 若 $a < b$ → 比重**下降**。
- 若 $a = b$ → 比重**不变**。

这个判断**无需计算**，直接看两个增长率的大小即可，是资料分析中最高频的"秒杀点"。
:::

### 7.2.6 平均数

::: formula 平均数体系
其中 $a$ = 总量的增长率，$b$ = 份数的增长率。

| 考点 | 公式 |
|---|---|
| 现期平均数 | $\dfrac{A}{B}$ |
| 基期平均数 | $\dfrac{A}{B} \times \dfrac{1 + b}{1 + a}$ |
| 平均数的增长率 | $\dfrac{a - b}{1 + b}$ |
:::

::: warn 易混点
**比重变化用"百分点"表示**（是减法），**平均数变化用"增长率"表示**（是相对变化）。
:::

### 7.2.7 倍数与比值

- $A$ 是 $B$ 的多少倍 $= A \div B$。
- $A$ 比 $B$ 多多少倍 $= \dfrac{A - B}{B} = A \div B - 1$。

::: warn 极易混淆
**"是几倍"和"多几倍"差 1。**
:::

### 7.2.8 百分点

百分点是两个百分数相减的单位，**不能与百分数混用**。

- 若某比重由 30% 上升到 35%，则上升了 **5 个百分点**（不是 5%）。
- 若表述为"上升了 5%"，则应为 $30\% \times 1.05 = 31.5\%$。

## 7.3 核心计算技巧（重点）

资料分析的计算全部是"估算"，掌握以下技巧即可应对绝大多数题目。

### 7.3.1 截位直除法（最常用，必须掌握）

**原理**：在除法运算中，分子分母同时截取若干位有效数字，不影响首位（或前两位）的结果。

| 选项差距 | 分母截位 | 说明 |
|---|---|---|
| 差距大（首位不同） | 截 2 位 | 如 34.7% 与 51.2%，只看首位即可 |
| 差距小（首位相同，第二位不同） | 截 3 位 | 需要更精确 |
| 差距很小（前两位相同） | 截 4 位 | 罕见，谨慎处理 |

**操作步骤**：

1. 看选项差距，决定截几位。
2. 分子截取（通常分子不动或同样截位），分母截位。
3. 做除法，取首位或前两位，与选项比对。

::: example 例 28 · 截位直除
> 计算 $4586 \div 1243 \approx ?$
>
> A. 3.7　B. 4.2　C. 5.1　D. 6.3

**解析**：选项首位各不相同，分母截 2 位：$1243 \rightarrow 12$，则 $4586 \div 12 \approx 382$，注意小数点量级，实际结果约为 3.82。与选项比对，最接近 A（精确值 $4586 \div 1243 = 3.69\cdots$）。**答案 A**。
:::

### 7.3.2 首数法与尾数法

- **首数法**：只需确定结果的首位数字，即可选出答案（适用于选项首位不同）。
- **尾数法**：只做末位（或末两位）运算，用于加减法的快速验算。

**技巧**：多个数相加时，只加末位即可确定答案的末位，快速排除。

### 7.3.3 特征数字法（分数化百分数）

把常见的百分数换成相应的分数，使计算变成简单乘除。必背对照表见 [附录 A 速算对照表](/ch/fujian#附录-a-常用速算对照表分数与百分数互化)，核心 20 个如下：

| 分数 | 百分数 | 分数 | 百分数 |
|---|---|---|---|
| 1/2 | 50% | 1/11 | 9.09% |
| 1/3 | 33.3% | 1/12 | 8.33% |
| 1/4 | 25% | 1/13 | 7.69% |
| 1/5 | 20% | 1/14 | 7.14% |
| 1/6 | 16.7% | 1/15 | 6.67% |
| 1/7 | 14.3% | 1/16 | 6.25% |
| 1/8 | 12.5% | 1/17 | 5.88% |
| 1/9 | 11.1% | 1/18 | 5.56% |
| 1/10 | 10% | 1/19 | 5.26% |
| 2/3 | 66.7% | 3/4 | 75% |

::: example 例 29 · 特征数字法
> 某年某地区 GDP 为 12500 亿元，比上年增长 12.5%。则上年 GDP 约为多少亿元？
>
> A. 10900　B. 11100　C. 11300　D. 11500

**解析**：基期量 $= \dfrac{12500}{1 + 12.5\%}$。用特征数字法：$12.5\% = \dfrac{1}{8}$，则 $1.125 = \dfrac{9}{8}$。所以基期量 $= 12500 \times \dfrac{8}{9} = \dfrac{100000}{9} \approx 11111$。与选项比对，最接近 B。**答案 B**。
:::

### 7.3.4 有效数字法（乘法）

乘法取两位（或三位）有效数字相乘，其余位四舍五入。

| 舍位规则 | 说明 |
|---|---|
| 第 3 位 ≤ 4 | 直接舍去（如 1.24 → 1.2） |
| 第 3 位 ≥ 6 | 进位（如 1.28 → 1.3） |
| 第 3 位 = 5 且后有非零数 | 进位 |
| 第 3 位 = 5 且后无数字 | 前一位为偶则舍，为奇则进（银行家舍入） |

::: tip 误差抵消
乘法取位时，若两数**一个放大、一个缩小**，误差可相互抵消，结果更准。
:::

### 7.3.5 错位加减法

用于减法或"接近 1"的除法，通过补数简化。

- **补数思想**：计算 $1 - r$（如 $1 - 13.7\% = 86.3\%$），直接用 100% 减去即可；计算 $\dfrac{A}{1 - r}$ 时，可先算 $\dfrac{A}{1 - r} \approx A \times (1 + r)$（当 $r$ 较小时，误差可接受）。
- **减法技巧**：被减数与减数同加减一个数，差值不变。如计算 $8432 - 2687$，可变为 $8432 - 2700 + 13 = 5745$。

### 7.3.6 分数比较大小（化同法与差分法）

分数比较大小是资料分析的高频考点（多出现在"以下哪个比重最大 / 最小"类题目），有三种工具：

**（1）直除比较**：直接算出各分数的大致数值（保留两位小数即可），比大小。适合选项差距较大时。

**（2）化同法**：两个分数的分子分母差距较大时，把其中一个分数的分子分母**同时乘（除）同一个数**，使两者分子（或分母）接近，再比较。分子相同看分母，分母小者大；分母相同看分子，分子大者大。

**（3）差分法**：适用于两个分数**非常接近**（通常差距在 10% 以内）的情形。比较 $\dfrac{a}{b}$ 与 $\dfrac{c}{d}$（设 $a > c$、$b > d$）：

- **大分数** $= \dfrac{a}{b}$，**小分数** $= \dfrac{c}{d}$
- **差分数** $= \dfrac{a - c}{b - d}$

判定规则：若差分数**大于**小分数 → 大分数**大于**小分数；反之亦然。

::: memo 口诀
**差分数与小分数比，同向则大，反向则小。**
:::

::: example 例 30 · 差分法
> 比较 $\dfrac{187}{345}$ 与 $\dfrac{176}{325}$ 的大小。

**解析**：两分数非常接近（都约等于 0.54），适合差分法。分子分母都是前者大，故大分数 $= \dfrac{187}{345}$，小分数 $= \dfrac{176}{325}$。差分数 $= \dfrac{187 - 176}{345 - 325} = \dfrac{11}{20} = 0.55$。小分数 $\approx 0.54$。差分数（0.55）**大于**小分数（0.54），故大分数**大于**小分数，即 $\dfrac{187}{345} > \dfrac{176}{325}$。（验算：$\dfrac{187}{345} \approx 0.5420$，$\dfrac{176}{325} \approx 0.5415$，结论正确。）
:::

::: warn 适用边界
差分法只在两个分数"很接近"时才使用。若分子分母差距较大（如比较 $\dfrac{32}{79}$ 与 $\dfrac{25}{68}$），应改用**化同法**——把 $\dfrac{25}{68}$ 的分子分母同乘 1.28 得到 $\dfrac{32}{87}$，与 $\dfrac{32}{79}$ 分子相同，分母小者大，故 $\dfrac{32}{79} > \dfrac{25}{68}$。
:::

### 7.3.7 增长量比较技巧

比较两个量的增长量大小，**多数情况下无需真正计算**。设 $A$、$B$ 为现期量，$a$、$b$ 为增长率：

::: formula 增长量
$$\text{增长量} = \frac{\text{现期量} \times \text{增长率}}{1 + \text{增长率}}$$
:::

::: memo 口诀"大大则大"
若 $A > B$ 且 $a > b$（现期量更大、增长率更高），则甲的增长量必然大于乙。

当不满足"大大则大"时，比较 **现期量 × 增长率** 的大小即可（因为分母 $(1+r)$ 影响较小）。
:::

### 7.3.8 混合增长率（十字交叉法）

当某整体由两部分组成时，整体增长率介于两部分增长率之间，且**偏向基期量较大的一方**。用十字交叉法可以精确求出两部分基期量之比。

::: example 例 31 · 增长率混合
> 某企业上半年收入增长 10%，下半年收入增长 20%，全年收入增长 14%。则上半年与下半年的收入之比约为：
>
> A. 2 : 1　B. 3 : 1　C. 1 : 2　D. 1 : 3

**解析**：用十字交叉。

```
上半年 10%          20% - 14% = 6
        14%
下半年 20%          14% - 10% = 4
```

上半年 : 下半年 $= 6 : 4 = 3 : 2$。注意此处交叉得到的是**基期量之比**，最接近 3 : 1（考虑到下半年基期量略大），选 B。**答案 B**。
:::

### 7.3.9 年均增长率比较的秒杀

比较多个方案的年均增长率时，**不必开方**：

若方案甲"末期值 ÷ 初期值"为 $M_1$、年数为 $n_1$，方案乙为 $M_2$、$n_2$，则只需比较 $M_1$ 与 $M_2$ 在"对齐年数"后的相对大小。实用做法：把（末期值 ÷ 初期值）统一换算到相同年数（用幂的近似展开），或直接比较"总增长率 ÷ 年数"。

## 7.4 综合技巧运用示例

::: example 例 32 · 基期 + 比重变化
> 2025 年某市规模以上工业增加值 1200 亿元，比上年增长 8.5%；其中高技术产业增加值 300 亿元，比上年增长 15%。
> **问题一**：2024 年该市规模以上工业增加值约为多少亿元？
> **问题二**：2025 年高技术产业增加值占规模以上工业增加值的比重，与上年相比是上升还是下降？

**解析**：

**问题一**：基期量 $= \dfrac{1200}{1 + 8.5\%}$。用截位直除：$\dfrac{1200}{1.085} \approx 1106$。若用特征数字，$8.5\% \approx \dfrac{1}{12}$（8.33%），$1.085 \approx \dfrac{13}{12}$，则 $1200 \times \dfrac{12}{13} = \dfrac{14400}{13} \approx 1108$。答案约 1106～1108 亿元。

**问题二**：比重升降看两个增长率的大小。部分（高技术产业）增长率 $a = 15\%$，整体（规上工业）增长率 $b = 8.5\%$。$a > b$ → **比重上升**。无需计算具体数值。
:::

::: example 例 33 · 比值变化
> 某地区 2025 年城镇居民人均可支配收入 48000 元，比上年增长 6.2%；农村居民人均可支配收入 21000 元，比上年增长 8.5%。
> 问：2025 年城乡居民收入比约为多少？与上年相比是扩大还是缩小？

**解析**：收入比 $= \dfrac{48000}{21000} \approx 2.29$（用截位直除：$48 \div 21 \approx 2.29$）。

城乡收入比是否缩小，看**农村收入增速（8.5%）是否大于城镇收入增速（6.2%）**。农村增速更快 → 比值缩小。这是"比值变化看两个增速大小"的典型应用。
:::

## 7.5 资料分析备考建议

1. **公式必须背到"条件反射"**。看到"基期"就想到 $\div(1+r)$，看到"比重变化"就想到 $a$ 与 $b$ 比大小。
2. **速算对照表每天默写一遍**，直到 $1/7 = 14.3\%$、$1/9 = 11.1\%$、$1/12 = 8.3\%$ 脱口而出。
3. **限时训练**：目标 20 题 25 分钟，单题 75 秒。前 10 题控制在 10 分钟内。
4. **做题时强制自己"只写式子不列竖式"**。所有计算都用估算完成，这是提速的关键。
5. **总结"看问法定考点"的对照表**（下表），做到读题即知考什么：

| 题干关键词 | 考点 |
|---|---|
| "约为多少亿元"（某年的值） | 基期量 = 现期 ÷ (1 + r) |
| "增长了多少" | 增长量 = 现期 × r ÷ (1 + r) |
| "增长了百分之几" | 增长率 |
| "占比 / 比重 / 结构" | 比重 |
| "平均 / 每 / 单位" | 平均数 |
| "是……的几倍" | 倍数 |
| "上升 / 下降了几个百分点" | 比重变化 |
| "同比增长 / 环比增长" | 同比或环比增长率 |
| "年均增长" | 年均增长率或年均增长量 |
| "与上年相比，A 占 B 的比重" | 比重变化方向判定 |
