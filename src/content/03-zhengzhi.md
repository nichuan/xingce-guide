政治理论是全科目中"投入最少、见效最快"的模块。本章按可背诵的知识块组织，每一块都给出记忆锚点。

## 3.1 模块定位与考情

政治理论自 2025 年起从"常识判断"中独立出来，单独设模块，题量 20 题，占比约 15%。这是**投入产出比极高的模块**：内容范围明确、可背诵、不需要复杂推理，短期突击即可见效。

考查内容可归纳为五大板块：

| 板块 | 大致题量 | 核心内容 |
|---|---|---|
| 习近平新时代中国特色社会主义思想 | 8～10 题 | 核心要义、"十个明确""十四个坚持""十三个方面成就" |
| 马克思主义基本原理 | 3～4 题 | 唯物论、辩证法、认识论、唯物史观 |
| 毛泽东思想与党史 | 2～3 题 | 重要会议、重要著作、重大历史事件 |
| 党的方针政策与重要会议精神 | 3～4 题 | 重要全会精神、重大战略部署 |
| 时政热点 | 2～3 题 | 近一年国内外重大事件 |

## 3.2 马克思主义基本原理

马原部分重理解而非死记，下面按"两大板块 + 三大规律"的结构梳理。

### 3.2.1 辩证唯物论

| 原理 | 要点 | 常见考法 |
|---|---|---|
| 物质与意识 | 物质决定意识，意识对物质有能动反作用 | 判断"意识决定物质"式错误 |
| 规律的客观性 | 规律客观，人可认识并利用规律 | "人定胜天"式错误 |
| 世界的物质统一性 | 世界统一于物质 | 判断唯心主义观点 |

### 3.2.2 唯物辩证法（三大规律 + 五对范畴）

**三大基本规律**：

1. **对立统一规律**（矛盾规律）——辩证法的实质与核心。
   - 矛盾的普遍性与特殊性（共性 / 个性）。
   - 主要矛盾与次要矛盾、矛盾的主要方面与次要方面。
   - 常考："抓主要矛盾""两点论与重点论统一"。
2. **质量互变规律**——量变积累到一定程度引起质变，质变又为新的量变开辟道路。常考："防微杜渐""循序渐进"。
3. **否定之否定规律**——事物发展是螺旋式上升、波浪式前进。

**五对基本范畴**：原因与结果、必然与偶然、可能与现实、现象与本质、内容与形式。

### 3.2.3 认识论

- **实践是认识的基础**：实践是认识的来源、动力、目的，也是检验认识真理性的唯一标准。
- **认识过程的两次飞跃**：感性认识 → 理性认识；理性认识 → 实践。
- **真理的绝对性与相对性**。

### 3.2.4 唯物史观

- 社会存在决定社会意识，社会意识具有相对独立性。
- 生产力与生产关系、经济基础与上层建筑的矛盾运动。
- 人民群众是历史的创造者。

## 3.3 毛泽东思想与中国特色社会主义理论体系

| 理论成果 | 核心内容 | 记忆锚点 |
|---|---|---|
| 毛泽东思想 | 实事求是、群众路线、独立自主（活的灵魂） | "三大活的灵魂" |
| 邓小平理论 | 解放思想、实事求是；社会主义本质论；"一国两制" | 什么是社会主义、怎样建设社会主义 |
| "三个代表"重要思想 | 代表先进生产力、先进文化、最广大人民根本利益 | 建设什么样的党、怎样建设党 |
| 科学发展观 | 以人为本、全面协调可持续发展 | 实现什么样的发展、怎样发展 |

::: memo 党史必背节点
- **1921 年** 中共一大——中国共产党成立。
- **1927 年** 八七会议——确定土地革命和武装反抗国民党反动派的总方针。
- **1935 年** 遵义会议——确立毛泽东在党中央的领导地位，是党历史上生死攸关的转折点。
- **1945 年** 中共七大——确立毛泽东思想为党的指导思想。
- **1978 年** 十一届三中全会——实现伟大历史转折，开启改革开放。
- **2012 年** 中共十八大——进入新时代的起点。
- **2017 年** 中共十九大——确立习近平新时代中国特色社会主义思想为党的指导思想。
- **2022 年** 中共二十大——全面建设社会主义现代化国家的行动纲领。
:::

## 3.4 习近平新时代中国特色社会主义思想（核心板块）

这一部分是政治理论模块的绝对重点，建议按"**主题 → 关键词 → 核心表述**"的方式整理背诵。

**核心要义**：

- **"两个确立"**：确立习近平同志党中央的核心、全党的核心地位；确立习近平新时代中国特色社会主义思想的指导地位。
- **"两个维护"**：坚决维护习近平总书记党中央的核心、全党的核心地位；坚决维护党中央权威和集中统一领导。
- **"十个明确"**：习近平新时代中国特色社会主义思想的核心内容，涵盖党的领导、总任务、社会主要矛盾、总体布局、全面深化改革总目标等。
- **"十四个坚持"**：新时代坚持和发展中国特色社会主义的基本方略。
- **"十三个方面成就"**：新时代取得的历史性成就、发生的历史性变革。

**重要战略概念**：

| 概念 | 关键表述 |
|---|---|
| 中国式现代化 | 人口规模巨大、全体人民共同富裕、物质文明和精神文明相协调、人与自然和谐共生、走和平发展道路 |
| 新发展理念 | 创新、协调、绿色、开放、共享 |
| 新发展格局 | 以国内大循环为主体、国内国际双循环相互促进 |
| 高质量发展 | 全面建设社会主义现代化国家的首要任务 |
| 全过程人民民主 | 最广泛、最真实、最管用的民主 |
| 总体国家安全观 | 以人民安全为宗旨、政治安全为根本、经济安全为基础 |
| 人类命运共同体 | 全球发展倡议、全球安全倡议、全球文明倡议 |
| "四个全面"战略布局 | 全面建设社会主义现代化国家、全面深化改革、全面依法治国、全面从严治党 |

::: tip 答题技巧
1. **抓关键词**。政治理论题的正确选项通常完整、准确、用语规范；错误选项常在**程度、范围、主体**上做手脚（如把"根本"改成"重要"，把"领导"改成"参与"）。
2. **排除绝对化与常识性错误**。如"市场在资源配置中起决定性作用"必须搭配"更好发挥政府作用"，缺一半即为不完整。
3. **时政题看时间线**。重大会议精神与提法要注意"最新表述优先"——同一概念在不同会议上有更新，以最新为准。
:::

## 3.5 时政与其他板块备考建议

1. **每周整理一次时政**：按"经济、政治、科技、国际、民生"分类，每条只记 1 句话。
2. **重点记"首次、第一、最大、唯一"**等标志性信息，这类细节是命题点。
3. **马原部分重理解，不能只背结论**。材料分析式单选题（给一段话判断体现哪个原理）需要真正理解规律内涵。
